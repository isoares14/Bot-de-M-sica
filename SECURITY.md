# Política de segurança

## Relatando uma vulnerabilidade

Não publique detalhes de vulnerabilidades em issues abertas. Envie o relato de forma privada pelo recurso de security advisories do GitHub, incluindo uma descrição do impacto e instruções para reprodução.

## Credenciais

Tokens do Discord devem existir somente no arquivo `.env`, que não é versionado. Caso um token seja exposto, revogue-o imediatamente no Discord Developer Portal e gere um novo.
