# Como contribuir

Obrigado pelo interesse em contribuir com o Bot de Música.

## Preparação

1. Faça um fork do repositório.
2. Clone o seu fork.
3. Instale as dependências com `npm install`.
4. Crie uma branch com `git checkout -b minha-alteracao`.
5. Faça uma alteração focada em um único objetivo.

## Padrão do projeto

- Use nomes claros para arquivos, funções e variáveis.
- Não inclua credenciais ou dados gerados pelo bot.
- Preserve o idioma português nas respostas ao usuário.
- Atualize a documentação ao alterar comandos ou configuração.
- Execute `npm run check` antes de enviar a contribuição.

## Pull request

Descreva o problema resolvido, explique a solução e informe como a alteração foi validada. Relacione uma issue quando houver uma correspondente.
